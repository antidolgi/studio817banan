🔧 НАСТРОЙКА CCTV - ПОЛНЫЙ ГАЙД

Dahua NVR + 8 камер ST-VK2513 | Работает офлайн
⚠️ ПЕРЕД НАЧАЛОМ:
• Отключи правую ветку, работай только с левой (или наоборот)
• Не лезь на столбы — всё настраивается с ноутбука/монитора

📋 ЧАСТЬ 1: ПОДГОТОВКА

1
Подключи монитор к NVR (опционально, но удобно)
• HDMI или VGA кабель от NVR → в монитор
• USB-мышь в NVR
• Питание NVR в розетку → включи
2
Проверь питание камер
• Убедись, что PoE-коммутатор включен в розетку
• Все кабели от камер вставлены в порты коммутатора
3
Скачай софт на ноутбук (если нет монитора)
• Dahua ConfigTool
• ONVIF Device Manager (универсальный)

🔌 ЧАСТЬ 2: УСТРАНЕНИЕ КОНФЛИКТА IP

💡 Суть проблемы: все камеры имеют заводской IP 192.168.1.10. Когда их несколько в сети → конфликт → камеры "прыгают" в списке.

Способ А: Через монитор (проще)

1
Зайди в меню NVR
• На мониторе: клик правой кнопкой мыши → Меню → введи пароль (по умолчанию пусто или admin)
2
Найди камеры
• Меню → Camera → Register
• Нажми Device Search
• Появятся камеры со статусом Conflict или Offline
3
Смени IP камерам ВРУЧНУЮ
• Выдели первую камеру → Modify
• Впиши:
IP: 192.168.1.101
Mask: 255.255.255.0
Gateway: 192.168.1.1
• Протокол: ONVIF
• Порт: 80 (если не работает → 8899)
• Логин: admin, Пароль: 12345
• Нажми OK
4
Повтори для всех 8 камер
Используй таблицу:
КамераГдеНовый IPПорт NVR
К1Въезд левая192.168.1.101PoE-1
К2Въезд правая192.168.1.102PoE-2
К3Левый ближний192.168.1.103PoE-3
К4Правый ближний192.168.1.104PoE-4
К7Левая середина192.168.1.105PoE-5
К5Левый дальний192.168.1.106PoE-6
К8Правая середина192.168.1.107PoE-7
К6Правый дальний192.168.1.108PoE-8
5
Проверь статус
• После смены IP статус каждой камеры должен стать ✅ Online
• Если Offline → проверь обжим, питание, порт удлинителя

Способ Б: Через ноутбук (если нет монитора)

1
Настрой сеть ноутбука
• Параметры → Сеть → Ethernet → Свойства адаптера
• IPv4 → Свойства → "Использовать следующий IP":
IP: 192.168.1.200
Mask: 255.255.255.0
Gateway: 192.168.1.1
2
Запусти ONVIF Device Manager
• Программа найдёт камеры даже при конфликте
• Выдели камеру → вкладка Network → Set IP
• Впиши новый IP из таблицы выше → Apply
• Логин: admin, Пароль: 12345
3
Повтори для всех камер
• После смены всех IP перезагрузи коммутатор (выдерни питание на 10 сек)

⚙️ ЧАСТЬ 3: ФИНАЛЬНАЯ НАСТРОЙКА NVR

1. Форматирование диска

1
Меню → Storage → HDD → выбери диск → Format → дождись "Normal"

2. Настройка записи

1
Меню → Storage → Record
• Канал: [All]
• Режим: Motion Detection (экономит место)
• Расписание: 24/7
• ☑ Overwrite (перезапись при заполнении)
• Apply

3. Настройка сети (интернет)

1
Меню → Network → TCP/IP
• Тип: Static
• IP: 192.168.1.10 (если не конфликтует с роутером)
• Mask: 255.255.255.0
• Gateway: IP твоего роутера (обычно 192.168.1.1)
• DNS: 8.8.8.8
• Apply

4. Включение P2P (облачный доступ)

1
Меню → Network → P2P (или Cloud)
• ☑ Включи галочку Enable P2P
• Подожди 1-2 минуты → статус должен стать ✅ Online
• СФОТОГРАФИРУЙ QR-код!
• ЗАПИШИ серийный номер (SN)!
✅ ГОТОВО! Теперь система работает и доступна удалённо.

📱 ЧАСТЬ 4: ПРОВЕРКА С ТЕЛЕФОНА

1
Скачай DMSS
• iPhone: App Store → DMSS
• Android: Google Play → DMSS
2
Добавь устройство
• Открой DMSS → зарегистрируйся → нажми +
• Выбери Scan QR Code → отсканируй QR с экрана NVR
• Имя: [Название объекта]
• Пароль: твой пароль админа NVR
3
Проверь
• Должны появиться все 8 камер
• Нажми на любую — должно пойти видео

✅ ФИНАЛЬНЫЙ ЧЕК-ЛИСТ

  • ☐ Все 8 камер в статусе Online ✅
  • ☐ У каждой камеры уникальный IP (101-108)
  • ☐ HDD отформатирован, запись включена
  • ☐ P2P статус: Online
  • ☐ QR-код сфотографирован, серийник записан
  • ☐ DMSS настроен, видео идёт с телефона
💡 Если камера не подключается:
• Проверь протокол: должен быть ONVIF
• Попробуй порт 8899 вместо 80
• Сбрось камеру кнопкой Reset (10 сек) → настрой заново
