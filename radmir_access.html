Просмотр камер + запись на ПК/сервер
✅ Что уже сделано монтажником:
• Все 8 камер настроены и работают
• Включён облачный доступ (P2P)
• QR-код и серийный номер записаны

📱 ВАРИАНТ 1: ПРОСМОТР С ТЕЛЕФОНА/ПЛАНШЕТА

1
Скачай приложение
• iPhone: App Store → DMSS
• Android: Google Play → DMSS
2
Зарегистрируйся
• Открой DMSS → нажми Регистрация
• Введи телефон или email → подтверди код
3
Добавь объект
• Нажми + (Добавить устройство)
• Выбери Сканировать QR-код
• Отсканируй QR-код, который прислал монтажник (или введи серийный номер вручную)
• Имя: [Название объекта]
• Пароль: [пароль админа NVR] (спроси у монтажника)
4
Смотри камеры
• В главном экране появятся все 8 камер
• Нажми на любую — пойдёт живое видео
• Свайп влево/вправо — переключение камер

🎬 Запись на телефон (опционально)

1
В режиме просмотра нажми ⋮ (меню) → Запись
• Видео сохранится в галерею телефона

💻 ВАРИАНТ 2: ПРОСМОТР + ЗАПИСЬ НА ПК / СЕРВЕР

💡 Этот способ позволяет вести непрерывную запись на жёсткий диск компьютера или сервера.

Шаг 1: Скачай SmartPSS Lite

1
Официальная ссылка:
www.dahuasecurity.com/support/download
• Найди раздел Software → SmartPSS Lite
• Скачай версию для Windows (или Mac)

Шаг 2: Установи и запусти

1
• Запусти установщик → следуй инструкциям
• При первом запуске создай локального пользователя (запомни пароль)

Шаг 3: Добавь устройство

1
Способ А: Через P2P (проще, не нужен белый IP)
• В главном окне нажми Devices → Add
• Метод добавления: SN / P2P
• Введи:
SN: [серийный номер от монтажника]
Имя: [любое]
Логин: admin
Пароль: [пароль админа NVR]
• Нажми Add → статус должен стать ✅ Online
2
Способ Б: Через прямой IP (если есть белый IP или доступ в локальную сеть)
• Метод добавления: IP/Domain
• Введи:
IP: [внешний IP объекта или локальный 192.168.1.10]
Порт: 37777
Логин/пароль: как выше

Шаг 4: Просмотр в реальном времени

1
• Перейди во вкладку Live View
• Слева — список устройств, раскрой свой объект → появятся 8 камер
• Перетащи камеры на сетку экрана (1/4/9/16 окон)
• Двойной клик — полноэкранный режим

Шаг 5: Настройка записи на ПК

1
Настрой хранилище:
• Меню (шестерёнка) → Storage
• Выбери диск для записи (должен быть отформатирован в NTFS)
• Нажми Format (если требуется)
2
Включи запись:
• Меню → Record
• Выбери устройство → каналы (или [All])
• Режим записи:
  • Continuous — непрерывная запись (требует много места)
  • Motion Detection — только при движении (экономит 70-90% места)
• Расписание: 24/7 или настрой по дням/часам
• ☑ Включи Overwrite (перезапись при заполнении)
• Нажми Apply
3
Проверь запись:
• Подожди 5-10 минут → зайди в Playback
• Выбери дату/канал → нажми Search
• Если запись есть — на временной шкале появятся синие сегменты

Шаг 6: Экспорт записи (если нужно)

1
• Вкладка Playback → выбери камеру, дату, время
• Нажми Export
• Выбери формат: MP4 (универсальный) или DAV (родной Dahua)
• Укажи папку для сохранения → Start

Смени пароль по умолчанию

• Задай сложный пароль (8+ символов, буквы+цифры)
2
Запиши новые данные
• Новый пароль админа:
_________________________
• Серийный номер NVR (SN):
_________________________
• QR-код: сохрани фото в облако/на флешку
3
Проверь доступ
• Попробуй зайти с телефона НЕ из локальной сети (отключи WiFi, включи мобильный интернет)
• Если видео идёт — настройка удалённого доступа работает
