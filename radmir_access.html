💻 ВАРИАНТ 2: Просмотр и запись на ПК / Сервер

💡 Данный способ позволяет вести непрерывную или событийную запись на жесткий диск компьютера или выделенного сервера.

Шаг 1: Установка SmartPSS Lite

1
Скачайте официальное ПО:
www.dahuasecurity.com/support/download
• Раздел Software → SmartPSS Lite
• Выберите версию для Windows (рекомендуется) или macOS

Шаг 2: Добавление регистратора

1
Метод P2P (без белого IP, работает через интернет):
• Запустите SmartPSS → вкладка Devices → Add
• Метод: SN / P2P
• Введите:
  `SN: [Серийный номер из меню NVR]`
  `Device Name: [Любое название]`
  `User Name: admin`
  `Password: Vologda2026!`
• Нажмите Add → статус изменится на ✅ Online

Шаг 3: Настройка записи на диск

1
Подготовка хранилища:
• Меню (шестерёнка) → Storage
• Выберите диск для архива (должен быть NTFS)
• При необходимости нажмите Format
2
Включение архивации:
• Меню → Record
• Выберите устройство → каналы (или [All])
• Режим:
  • Continuous — сплошная запись (максимальный объем)
  • Motion Detection — только при движении (экономия 70-90% места)
• Расписание: 24/7
• Включите Overwrite (автоперезапись при заполнении)
• Нажмите Apply
3
Проверка:
• Перейдите во вкладку Playback
• Выберите камеру и дату → нажмите Search
• Наличие синих сегментов на таймлайне подтверждает успешную запись

Шаг 4: Экспорт фрагментов

1
• Вкладка Playback → выберите камеру, дату, время начала/конца
• Нажмите Export
• Формат: MP4 (универсальный) или DAV (родной)
• Укажите путь сохранения → Start
